# 04 AI 辅助内容、个人修改与验证

本项目使用 Codex 辅助拆解题目、制定工具接口、生成初版代码和文档。个人检查聚焦三点：模型是否真的在工具结果之后选择动作、引用能否回到文档原文、冲突和失败是否会被误写成成功。资料和示例均为本项目合成，不包含真实公司文件。

具体修改与验证过程：

1. 将“回答有据、冲突追问、工具失败、相似问题”写成可运行场景与断言，而不是只展示一段回答文本。
2. 将制度声明的 `quote` 与文档段落核对；加载资料时若找不到原文，直接报错。
3. 为 `submit_answer` 加入逐字引文、已读文档、同主题多文档和冲突校验；编写伪造引文测试确认会被拒绝。
4. 在 Windows 运行 CLI 时发现默认终端编码不能打印某些符号，调整为 UTF-8 输出并重新跑示例。
5. 使用 `unittest` 运行关键测试，再保存 `examples/mock/` 的实际输入、输出和 Trace。

DeepSeek 接口使用官方 Chat Completions 文档核对参数与工具格式；真实模型运行尚待本机配置新密钥。先前在聊天中暴露的密钥不写入代码、配置、测试或提交文件。模型选择动作的真实效果必须通过后续 DeepSeek 实测评估，离线 Mock 只能验证程序流程。
