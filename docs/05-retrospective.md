# 05 最难问题、学习收获与下一步

## 最难问题

资料冲突不能被“日期较新”这种看似合理的捷径掩盖。D01 和 D02 对同范围的一般费用报销给出 30 天与 15 天，但没有任何一份写明废止或替代关系；安全的答案应列出两条原文并请求确认。为此将冲突检查做成可观察工具，并在最终输出前要求双引用。

另一难点是区分模型决策与程序护栏。固定校验负责阻止伪造引文和未核查的确定答案；模型仍负责决定检索什么、读取什么、何时核对冲突及何时结束。Trace 只保存简短可公开依据和工具结果，不索取模型内部思维。

## 学习收获

- 给结论附文档 ID 还不够，必须核查引用片段确实存在于已读原文中。
- 资料不足、工具故障和模型故障应分开返回，评阅者才能判断失败发生在哪一层。
- Mock 路径可以证明流程可复现，但必须与真实模型效果分开评估。
- 有界循环让失败可结束、费用可控制，也使 Trace 更容易复查。

## 下一步

1. 在本机安全配置新的 DeepSeek 密钥，实跑正常、冲突、资料不足和相似问法，记录成功与失败。
2. 若真实模型漏读 D02，改进检索候选展示和系统提示，再重新评估；保留失败记录。
3. 扩展范围包含和显式替代关系，处理复杂制度优先级；增加语义检索并度量召回。
4. 进入真实企业环境前加入身份、权限、审计和隐私处理，再考虑生产部署。
